# Funcionalidades MVP

## 1. Autenticacao
- login
- cadastro
- recuperacao de senha

## 2. Dashboard
Exibir:
- saldo total
- proximo pagamento
- numero de membros
- emprestimos ativos
- notificacoes

## 3. Grupos
- criar grupo
- editar dados do grupo
- listar grupos do utilizador

Exemplo:
- nome: Familia Silva
- membros: 12
- contribuicao: 10000 AOA por mes

## 4. Membros
- adicionar membro ao grupo
- remover membro
- definir administrador

## 5. Contribuicoes
- registar pagamento
- acompanhar status por membro

Exemplo:
- membro: Leonardo
- valor: 10000 AOA
- status: pago
- data: 09/07

## 6. Emprestimos
- solicitar emprestimo
- aprovacao por administrador
- calculo automatico de parcelas, juros e data limite

## 7. Historico
- timeline de operacoes do grupo
- registos imutaveis para auditoria funcional

## 8. Calendario
- proximas cobrancas
- proximos sorteios
- vencimentos de parcelas

## 9. Notificacoes
Mensagens de lembrete:
- voce ainda nao pagou
- seu emprestimo vence amanha
